Context

The export’s decision 0001 is an accepted historical record; it has not been edited. Its subject-only rule contradicts the executable classifier and mixes distinct problems in incident 4471. Similar words are not evidence of a shared cause.

Replacement rule for this review

  1. Deduplicate export rows by report ID, keeping the last occurrence as the supplied code does.
  2. Look up the tenant’s locale and booking form; read the channel and report body.
  3. Use the executable cause rule to propose a group, then check that the symptom fits it.
  4. Merge only when evidence supports the same cause. Subject similarity is a search aid, not a merge test.
  5. Keep unknown tenants and contradictory symptoms visible for investigation, rather than treating null causes as matches.
